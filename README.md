# Мой дом (RuStore)

Локальное Android-приложение для учёта домашнего имущества.

## Stack

- Expo SDK 57 / React Native 0.86 / React 19
- Expo Router, SQLite, TypeScript strict
- Package: `com.calculatorplatform.myhome`

## Scripts

```bash
npm start
npm run android
npm run test
npm run typecheck
npm run lint
npm run doctor
```

## Phase status

Phase 0–1: foundation, data model, application shell (five tabs).
